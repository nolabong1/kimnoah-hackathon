# AI 퀴즈 선택지별 진단 피드백

## 목적

퀴즈 결과에서 정답과 공통 해설만 보여주는 대신, 학습자가 실제로 고른
오답이 어떤 사고 오류에 가까운지 설명하고 다음에 확인할 행동을 안내한다.
제출 시 추가 AI 호출을 하지 않도록 퀴즈 생성 시 네 선택지의 피드백을 함께
만들어 문항 JSON과 응시 스냅샷에 저장한다.

## 문항 구조

새 문항은 선택지 순서와 같은 `choice_feedback` 네 개를 가진다.

- `diagnosis_type`: 제한된 오답 유형 또는 `correct_reasoning`
- `feedback`: 해당 선택이 왜 그럴듯하지만 맞지 않는지 설명
- `next_step`: 정답을 대신 말하지 않고 다시 확인할 개념·조건·계산 안내

지원하는 오답 유형은 다음과 같다.

- 개념 혼동
- 조건 누락
- 풀이 절차 오류
- 계산 오류
- 경계값 오류
- 지나친 일반화
- 표현 해석 오류
- 추가 점검 필요

정답 선택지만 `correct_reasoning`을 사용할 수 있고, 오답 선택지에는 사용할
수 없다. 선택지와 피드백은 반드시 각각 네 개이며 같은 인덱스로 대응한다.

## 결과 화면

오답 문항은 기존 정답과 공통 해설에 앞서 다음 내용을 표시한다.

1. 한국어 오답 유형
2. 선택한 답에 대한 구체적인 점검
3. 다음에 확인할 짧은 행동

과거에 저장되어 `choice_feedback`이 없는 퀴즈는 오류로 처리하지 않고 기존
정답·해설 화면을 그대로 사용한다.

## 보존되는 규칙

- 답안 제출 시 OpenAI를 호출하지 않는다.
- 채점과 숙련도 계산은 기존 서버 RPC 결과를 사용한다.
- 재응시, 만점 완료 조건, EXP와 자동 복습 규칙을 변경하지 않는다.
- DB 열이나 테이블을 추가하지 않는다.
- 선택지별 피드백은 진단 안내이며 확정적인 심리·행동 원인으로 표현하지 않는다.
